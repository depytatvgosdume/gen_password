# Java Password Generator
Desktop application built with Java Swing for generating secure passwords. Features customizable length, real-time strength evaluation, password history management, and one-click clipboard integration. Demonstrates practical usage of event-driven GUI programming, layout managers, and system clipboard interaction in Java.
## ✨ Features
- Customizable Length: Generate passwords from 4 to 50 characters.
- Strength Indicator: Real-time visual feedback (color-coded) showing password reliability.
- History Management: Keeps track of the last 10 generated passwords with auto-scrolling.
- Clipboard Integration: One-click copying of the latest password to the system clipboard.
- User-Friendly UI: Clean layout using BorderLayout, BoxLayout, and FlowLayout with proper padding and borders.
- Input Validation: Prevents invalid input and handles non-numeric values gracefully.
- Keyboard Support: Press Enter in the length field to instantly generate a password.
## Tecn Stack 
- Language: Java (8+)
- GUI Framework: Java Swing (javax.swing.*)
- Data Structures: ArrayList<String> for dynamic history storage
- System Integration: Toolkit for clipboard access
## 🚀 How to Run
Clone the repository:
```bash
git clone https://github.com/depytatvgosdume/gen_password.git
cd gen_password
```
Compile the source files:
``` bash
javac Main.java 
```
Launch the application:
``` bash
java Main
```
